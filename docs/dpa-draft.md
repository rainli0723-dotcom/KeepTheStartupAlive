# KTSA 数据处理协议 DPA 草案

本草案用于企业试点和售前沟通，正式商用前应由法律顾问审阅。

## 角色定义

- 客户：数据控制方，决定上传哪些企业资料和如何使用模拟结果。
- KTSA 服务方：数据处理方，按照客户配置处理数据。
- LLM 服务商：可能作为子处理方处理模型请求。

## 处理范围

处理数据包括企业资料、角色配置、会议记录、复盘报告、审计日志、LLM 调用元数据和后台任务状态。

## 处理目的

仅用于提供经营模拟、数字孪生会议、报告导出、权限管理、审计、安全排障和客户支持。

## 子处理方

如果使用第三方 LLM API，应在正式合同中列明供应商、数据区域、保留策略和安全承诺。私有化部署可改用客户自有模型网关。

## 安全措施

- 租户隔离。
- 成员权限控制。
- 会话管理。
- 审计日志。
- 报告分享链接过期和撤销。
- 数据删除流程。
- 备份恢复流程。

## 数据删除和返还

合同终止或客户要求时，应支持导出企业数据，并删除业务数据。审计日志可按法规或合同约定保留。

## 事故通知

如发生影响客户数据的安全事件，应在合同约定时间内通知客户，并提供影响范围、补救措施和后续改进。

## 审计

企业客户可要求提供安全说明、部署说明、备份恢复说明和关键控制项证明。正式审计方式应在合同中约定。
