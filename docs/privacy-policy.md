# KTSA 隐私政策

> **版本：** v2.0（草案，正式商用前需法律顧問審閱）
> **生效日期：** 待定
> **適用範圍：** KTSA SaaS 平台（ktsa-delta.vercel.app）及私有化部署實例

---

## 1. 概述

本隱私政策說明 KTSA（Keep The Startup Alive）平台如何收集、使用、存儲、分享和刪除用戶資料。使用 KTSA 即表示你同意本政策所述的資料處理方式。

## 2. 我們收集的資料

### 2.1 帳號資訊
- 姓名、電子郵件地址、企業名稱
- 帳號角色（管理員/編輯者/唯讀成員）
- 密碼雜湊值（PBKDF2 加鹽，不可逆）

### 2.2 業務資料
- 公司檔案：名稱、行業、產品、市場定位、發展階段、財務指標、治理結構
- 上傳文件：公司背景文件（PDF/Word/Markdown/TXT）、角色資料文件
- 數字孿生配置：角色名稱、能力值、個性設定、溝通風格、決策偏好
- AI 蒸餾畫像：從上傳文件中提取的角色語言風格和決策特徵

### 2.3 模擬資料
- 經營事件記錄（20 輪）
- 會議記錄（角色觀點、用戶發言、會議結論）
- 決策方案與用戶選擇
- 組織狀態指標變化歷史
- 最終覆盤報告（評分、關鍵驅動因素、決策軌跡、替代結局）

### 2.4 系統資料
- 登入會話記錄（token 雜湊，非明文）
- 審計日誌（操作者、操作類型、時間戳、元資料）
- LLM 調用記錄（模型名稱、token 用量、預估成本、狀態、錯誤訊息）
- 分享連結記錄（token 雜湊、過期時間、狀態）
- 後台任務狀態（排隊/運行中/完成/失敗）

### 2.5 不收集的資料
- 信用卡/支付資訊（由第三方支付服務商直接處理）
- 個人身份證件號碼
- 精確地理位置
- 生物識別資料

## 3. 資料使用目的

| 用途 | 說明 |
|------|------|
| 提供核心服務 | 經營模擬、數字孿生會議、覆盤報告生成、文件匯出 |
| 權限控制 | 基於角色的訪問控制（RBAC）、租戶隔離 |
| 審計與合規 | 記錄關鍵操作、支援合規審查 |
| 系統運維 | 故障排查、效能監控、LLM 成本統計 |
| 產品改進 | 匿名化的使用數據分析（不包含客戶業務內容） |
| 客戶支援 | 回應技術問題、提供使用指導 |
| 法律義務 | 遵守適用法律法規要求 |

## 4. 資料隔離

KTSA 採用多租戶架構，所有客戶資料在資料庫層級通過 `tenantId` 強制隔離：

- A 企業的成員無法訪問 B 企業的工作區、角色、會議、報告或文件
- API 層面通過 scope 函數自動注入租戶過濾條件
- 分享連結通過 token 雜湊驗證，不依賴租戶上下文

## 5. LLM 資料處理

### 5.1 資料傳輸
模擬運行過程中，以下資料會作為上下文發送到配置的 LLM 服務商（預設為 DeepSeek）：
- 公司檔案摘要（不含完整上傳文件）
- 參會角色畫像和能力設定
- 當前輪次的經營事件和歷史會議摘要
- 用戶即時發言

### 5.2 資料留存
- LLM 調用記錄僅保存元資料（模型、token 數量、成本、狀態），不保存完整的 prompt 內容
- LLM 服務商的資料處理政策請參閱其各自的隱私政策

### 5.3 私有化部署選項
私有化部署的客戶可使用自有 LLM API Key 或私有模型網關，資料不會經過 KTSA 控制的第三方 LLM 服務商。

## 6. 資料存儲與保留

| 資料類型 | 預設保留期限 | 說明 |
|----------|------------|------|
| 帳號資訊 | 帳號存續期間 + 90 天 | 帳號刪除後保留必要的審計記錄 |
| 業務資料 | 合約期間 + 30 天 | 客戶可隨時手動刪除 |
| 模擬資料 | 合約期間 + 30 天 | 客戶可隨時手動刪除 |
| 審計日誌 | 依合約，預設 365 天 | 支援合規要求的長期保留 |
| LLM 調用記錄 | 依合約，預設 365 天 | 用於成本核算和故障排查 |
| 會話 token | 14 天或登出時立即清除 | HTTP-only Cookie |

## 7. 資料安全措施

| 安全層面 | 措施 |
|----------|------|
| 傳輸安全 | HTTPS/TLS 強制加密 |
| 密碼安全 | PBKDF2 加鹽雜湊，每密碼獨立鹽值 |
| 會話安全 | HTTP-only、Secure、SameSite Cookie |
| 存取控制 | RBAC 三級權限（admin/editor/viewer） |
| 租戶隔離 | 資料庫層級 tenantId 過濾 |
| 審計追蹤 | 關鍵操作完整記錄 |
| 文件上傳 | MIME 類型白名單、大小限制（20MB） |
| 分享連結 | Token 雜湊驗證、可設過期時間、支援撤銷 |
| 備份恢復 | 每日自動備份、Point-in-Time Recovery |
| LLM 安全 | 不記錄完整 prompt、請求雜湊去重 |

## 8. 資料分享與第三方

### 8.1 我們不會做的事
- 不出售客戶資料
- 不將客戶業務資料用於訓練公共 AI 模型
- 不在未經授權的情況下跨客戶共享資料

### 8.2 必要的子處理方

| 服務商 | 用途 | 資料類型 |
|--------|------|---------|
| DeepSeek（預設） | LLM API 調用 | 模擬上下文（不含完整文件） |
| Vercel | 應用託管 | 伺服器日誌（不含業務資料） |
| Neon | 資料庫託管 | 所有持久化資料（加密存儲） |

私有化部署客戶可使用自有基礎設施，無需使用上述子處理方。

## 9. 用戶權利

根據適用資料保護法律，用戶享有以下權利：

- **訪問權：** 請求查看我們持有的個人資料
- **更正權：** 要求更正不準確的個人資料
- **刪除權：** 要求刪除帳號和相關業務資料（管理員可在企業空間自行操作）
- **匯出權：** 要求匯出企業業務資料（支援 JSON 格式）
- **限制處理權：** 在某些情況下要求限制資料處理
- **反對權：** 反對基於合法利益的資料處理

行使上述權利請聯繫：`privacy@ktsa.dev`（正式上線前更新）

## 10. Cookie 政策

KTSA 使用以下 Cookie：

| Cookie 名稱 | 用途 | 類型 | 有效期 |
|------------|------|------|--------|
| `ktsa_session` | 身份驗證 | 必要 | 14 天或登出時清除 |
| `ktsa_trial` | 試用狀態 | 功能 | 試用期間 |

不使用第三方追蹤 Cookie 或廣告 Cookie。

## 11. 政策更新

本隱私政策如有重大變更，我們將通過以下方式通知：
- 在平台上發布更新版本
- 向註冊郵箱發送通知（重大變更）
- 更新文檔末尾的生效日期
