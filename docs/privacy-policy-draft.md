# KTSA 隐私政策草案

本草案用于企业试点和售前沟通，正式商用前应由法律顾问审阅。

## 收集的数据

KTSA 可能处理以下数据：

- 企业账号信息：姓名、邮箱、角色、企业空间信息。
- 业务资料：公司资料、上传文档、数字孪生资料、Skill 内容。
- 模拟数据：会议记录、决策方案、复盘报告、分享链接。
- 系统数据：登录会话、审计日志、LLM 调用日志、后台任务状态。

## 使用目的

数据用于：

- 提供企业经营模拟和数字孪生会议功能。
- 生成会议纪要、复盘报告和管理层交付物。
- 做权限控制、租户隔离、审计追踪和安全排障。
- 统计 LLM 成本、任务状态和系统健康情况。

## 数据隔离

KTSA 通过企业空间区分客户数据。接口读取和写入必须按 tenant 校验，避免不同企业之间互相访问。

## LLM 处理

客户资料可能作为上下文发送到配置的 LLM 服务。生产环境应使用客户认可的模型供应商、企业模型网关或私有化模型服务。

## 数据删除

管理员可以删除企业业务数据。删除操作会清理工作区、会议、报告、上传资料、LLM 任务和调用记录，并保留必要审计记录。

## 安全措施

- 密码哈希存储。
- HTTP-only 会话 Cookie。
- 成员权限分级。
- 审计日志记录关键操作。
- 只读分享链接支持过期和撤销。

## 联系方式

正式版本应填写服务提供方、数据保护联系人和企业客户支持渠道。
