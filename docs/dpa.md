# KTSA 數據處理協議（DPA）

> **版本：** v2.0（草案，正式商用前需法律顧問審閱）
> **生效日期：** 待定（與主服務協議同日生效）

---

## 1. 定義

| 術語 | 定義 |
|------|------|
| **控制者（Controller）** | 客戶 — 決定資料處理的目的和方式 |
| **處理者（Processor）** | KTSA 服務提供方 — 代表控制者處理個人資料 |
| **子處理者（Sub-processor）** | 處理者委託的第三方服務商（如 LLM API、雲端託管） |
| **個人資料** | 與已識別或可識別自然人有關的任何資訊 |
| **客戶資料** | 客戶上傳、配置或在服務中產生的所有資料（含個人資料和業務資料） |
| **處理** | 對資料執行的任何操作（收集、存儲、使用、傳輸、刪除等） |
| **安全事件** | 導致意外或非法破壞、遺失、更改、未授權披露或訪問個人資料的事件 |

## 2. 角色與責任

### 2.1 控制者（客戶）
客戶作為資料控制者：
- 決定上傳哪些資料
- 決定模擬中使用的角色設定和場景
- 負責取得必要的同意和合法基礎
- 負責遵守所在行業的資料保護法規

### 2.2 處理者（KTSA）
KTSA 作為資料處理者：
- 僅按客戶配置和指示處理資料
- 不將客戶資料用於自身目的（改善服務的匿名化數據除外）
- 通知客戶如發現無法遵守的指示

## 3. 處理範圍

### 3.1 資料類別

| 類別 | 示例 |
|------|------|
| 帳號資料 | 姓名、電子郵件、角色、企業名稱 |
| 業務資料 | 公司檔案、上傳文件、角色配置、蒸餾畫像 |
| 模擬資料 | 經營事件、會議記錄、決策方案、覆盤報告 |
| 系統資料 | 審計日誌、LLM 調用元數據、會話記錄 |

### 3.2 處理目的
僅限於提供合約約定的 KTSA 服務：經營模擬、數字孿生會議、報告生成匯出、權限管理、審計、安全排障和客戶支援。

### 3.3 處理期限
與主服務協議的有效期一致。終止後依第 8 條刪除或返還資料。

## 4. 子處理者

### 4.1 現有子處理者

| 子處理者 | 服務 | 資料位置 | 處理的資料 |
|----------|------|---------|-----------|
| DeepSeek | LLM API | 美國/全球 | 模擬上下文（不含完整上傳文件） |
| Vercel | 應用託管 | 美國 | 伺服器日誌 |
| Neon | 資料庫（PostgreSQL） | 美國（AWS us-east-1） | 所有持久化資料 |

### 4.2 子處理者變更
- KTSA 將在新增或更換子處理者前至少 30 天通知客戶
- 客戶可在通知後 14 天內提出合理異議
- 如無法解決異議，客戶可終止服務並按比例退款

### 4.3 子處理者義務
KTSA 與所有子處理者簽訂書面協議，要求其提供不低於本 DPA 的資料保護水準。

### 4.4 私有化部署例外
私有化部署客戶可使用自有 LLM API Key 和自有基礎設施，此時上述子處理者不適用。

## 5. 安全措施

KTSA 實施以下技術和組織措施：

### 5.1 技術措施

| 措施 | 說明 |
|------|------|
| 傳輸加密 | TLS 1.2+ 強制，HSTS 啟用 |
| 靜態加密 | 資料庫層級加密（AES-256） |
| 密碼保護 | PBKDF2 加鹽雜湊 |
| 存取控制 | 基於角色的訪問控制（admin/editor/viewer） |
| 租戶隔離 | tenantId 級別的資料庫過濾 |
| 會話管理 | HTTP-only Secure Cookie，14 天有效期 |
| 輸入驗證 | MIME 類型白名單，上傳大小限制 |
| 日誌監控 | 關鍵操作審計日誌，異常行為告警 |
| 備份 | 每日自動備份，Point-in-Time Recovery |

### 5.2 組織措施
- 僅授權人員可訪問生產系統
- 定期安全審查和依賴更新
- 員工保密協議
- 安全事件應變計劃

## 6. 安全事件通知

- 發現安全事件後 72 小時內通知客戶
- 通知內容包括：事件描述、受影響資料範圍、已採取的補救措施、客戶應採取的行動建議
- 持續更新調查進展
- 事件結束後提供完整報告和預防措施

## 7. 跨境資料傳輸

### 7.1 SaaS 部署
資料可能存儲和處理在美國（Vercel、Neon、DeepSeek 的伺服器位置）。KTSA 將依據適用的資料保護法律提供充分的保護措施（如標準合約條款 SCCs）。

### 7.2 私有化部署
客戶可將所有資料保留在自有基礎設施內（包括私有 LLM 模型網關），完全避免跨境傳輸。

## 8. 資料刪除與返還

### 8.1 服務期間
- 客戶管理員可隨時在企業空間刪除業務資料
- 客戶可隨時通過 API 或匯出腳本匯出企業資料（JSON 格式）

### 8.2 合約終止後
| 時間 | 行動 |
|------|------|
| 終止後 0-30 天 | 客戶可要求匯出全部企業資料 |
| 終止後 30 天 | 業務資料永久刪除 |
| 終止後 依合約/法規 | 審計記錄保留後刪除 |

### 8.3 刪除驗證
KTSA 在收到書面請求後 30 天內提供資料刪除的書面確認。

## 9. 審計權

### 9.1 安全文檔
KTSA 向企業客戶提供：
- 安全白皮書
- 私有化部署 Runbook
- 備份恢復流程說明
- 子處理者名單

### 9.2 正式審計
- 客戶可每年進行一次正式安全審計（費用由客戶承擔）
- 審計需提前 30 天書面通知
- 審計不得干擾 KTSA 的正常業務運營
- 審計結果在雙方同意下保密

## 10. 合規認證

正式商用後計畫獲取以下認證（時間表待定）：
- SOC 2 Type II
- ISO 27001
- GDPR 合規評估
