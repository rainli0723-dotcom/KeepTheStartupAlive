## 1. 执行摘要

### 1.1 产品概述

KTSA — Keep The Startup Alive，是一个 AI 驱动的企业级商业经营模拟沙盘与数字孪生决策平台。它将一家公司的组织档案、团队角色、商业场景、会议讨论、经营决策和复盘报告串联成一个完整的连续模拟系统，让用户在真实商业代价发生之前，先用 AI 数字孪生团队预演融资、增长、竞争、组织、合规和危机等关键经营情境。

### 1.2 核心价值

| 价值维度 | 说明 | 企业客户收益 |
|---|---|---|
| **风险前置** | 在真实经营代价发生前暴露决策风险 | 降低试错成本 40-60% |
| **决策质量** | 结构化多角色辩论替代经验直觉判断 | 提升决策可追溯性 80%+ |
| **团队训练** | 沉浸式 20 轮沙盘训练经营判断力 | 加速管理层成长周期 3-5 倍 |
| **复盘沉淀** | 自动生成结构化复盘报告和行动计划 | 减少复盘准备时间 90%+ |
| **批量评估** | 标准化流程批量评估团队决策质量 | 投后管理效率提升 5-10 倍 |
| **数据安全** | 多租户隔离、SSO、审计、私有化部署 | 满足企业合规要求 |

### 1.3 目标市场

KTSA 专注于以下五个核心企业市场：

- **创业加速器 / 孵化器**：批量训练创业团队，标准化经营能力评估
- **风险投资机构**：投前项目评估、投后决策质量监控、董事会沟通预演
- **企业内训 / 创新部门**：管理层战略推演、新业务孵化压力测试
- **商学院 / MBA 项目**：动态案例教学替代静态案例分析
- **政府创新园区**：入驻企业培育、创新能力量化评估

### 1.4 当前状态

项目已完成 MVP 开发并部署于 https://ktsa-delta.vercel.app，具备完整的产品化基础：

- 24 个数据库模型，支持完整多租户架构
- 34 个内置角色模板（5 大类别），7 种沙盘类型，6 种组织阶段
- 8 个行业演示模板（SaaS、跨境电商、医疗合规等）
- 4 种报告导出格式（Markdown/PDF/Word/PPT）
- 企业空间、SSO（OIDC）、审计日志、用量限制、LLM 成本追踪
- 私有化部署文档、安全白皮书、法律文本草案齐全
- 3 项 UI 优化待办尚未完成

### 2.2 目标市场细分

#### 2.2.1 创业加速器 / 孵化器市场

- 全球约有 2,000+ 活跃加速器项目
- 每个加速器平均服务 20-50 家创业公司/年
- 痛点：训练标准化程度低、导师时间有限、复盘难以量化
- KTSA 价值：标准化经营训练，减少 60% 导师辅导时间，输出可量化的评估报告

#### 2.2.2 风险投资机构市场

- 全球活跃 VC 约 3,000+ 家，管理资产 $3T+
- 典型投后管理覆盖 30-100+ 家被投企业
- 痛点：投后信息滞后、团队判断力难以客观评估、董事会沟通效率低
- KTSA 价值：季度经营预演替代被动等待报告，提前 3-6 个月发现风险信号

#### 2.2.3 企业内训 / 创新部门市场

- 全球 500 强中 70% 设有企业内部创新/战略部门
- 痛点：新业务孵化决策缺乏预演环境、管理层战略共识难以形成
- KTSA 价值：在投入真实资源前用 20 轮沙盘推演新业务可行性

#### 2.2.4 商学院市场

- 全球 Top 200 商学院，每年超过 50 万 MBA/EMBA 学员
- 痛点：案例教学静态化、缺乏动态决策训练、线上化程度不足
- KTSA 价值：动态案例库 + 多角色模拟 + 可重复运行的决策训练平台

### 2.3 竞争格局分析

#### 2.3.1 竞争矩阵

| 竞品 | 类型 | 核心能力 | KTSA 差异化优势 |
|---|---|---|---|
| **Harvard Business Publishing** | 案例教学 | 经典商业案例库 | 动态模拟而非静态案例，AI 角色实时辩论 |
| **StratX / Capsim** | 传统沙盘 | 标准化企业运营模拟 | 定制化数字孪生角色，资料蒸馏个性化 |

| **MURAL / Miro** | 协作白板 | 可视化讨论 | AI 驱动的内容生成和结构化决策路径 |
| **传统咨询（麦肯锡等）** | 咨询服务 | 人工战略推演 | 成本降至 1/100，可重复运行，24/7 可用 |

#### 2.3.2 KTSA 竞争优势

1. **数字孪生角色蒸馏**：通过上传文档自动学习角色语言风格、决策偏好和专业边界，而非简单提示词配置
2. **20 轮连续沙盘**：完整经营周期的连续模拟，而非单次问答
3. **结构化复盘报告**：自动生成管理层摘要、风险矩阵、决策路线图、行动计划
4. **企业级完工度**：多租户、SSO、审计、用量限制、成本追踪、4 种报告格式导出
5. **私有化部署**：支持企业内网部署、自有 LLM 模型网关、数据完全隔离
6. **行业模板丰富**：8 个预置行业模板，可快速演示和价值验证

### 3.2 核心用户画像

#### Persona A：加速器运营总监

- **背景**：负责加速器日常运营和创业营课程设计
- **痛点**：导师时间有限，难以给每家创业公司深度辅导；训练效果难以量化
- **需求**：标准化经营训练工具，可批量运行，输出可比较的评估报告
- **决策标准**：实施简单、无需技术团队支持、见效快、成本低于增加导师
- **使用场景**：创业营期间安排 3-5 轮沙盘推演，导师基于报告做针对性辅导

#### Persona B：VC 投后管理合伙人

- **背景**：管理 30-100+ 家被投企业，定期跟进经营状况
- **痛点**：被投企业信息不透明，董事会沟通形式化，问题发现太晚
- **需求**：季度经营预演沙盘，发现风险信号，评估创始人决策质量
- **决策标准**：数据安全、可私有化部署、输出可审计的报告、易推广至被投企业
- **使用场景**：每个季度要求被投企业完成一次经营沙盘推演，分析决策模式变化

#### Persona C：企业 L&D（学习与发展）总监

- **背景**：负责企业高潜人才培养和管理层战略思维训练
- **痛点**：传统培训课程理论多实践少，高管参与度低，ROI 难以度量
- **需求**：沉浸式经营模拟，贴近真实业务压力，管理层愿意参与
- **决策标准**：与企业行业相关、可定制、有数据证明效果、支持多部门协作
- **使用场景**：高管战略会上用 2 小时完成一次经营推演，识别战略盲区

#### Persona D：商学院教授

- **背景**：教授 MBA 战略管理、创业管理、公司金融课程
- **痛点**：案例教学学生参与度两极分化，无法模拟动态决策
- **需求**：可嵌入课程体系的经营模拟工具，支持评分和课堂讨论
- **决策标准**：学术理论基础扎实、可定制案例参数、学生体验好、有数据分析
- **使用场景**：设置课前沙盘推演作业，课堂讨论决策路径和结果

## 4. 产品定位与价值主张

### 4.1 产品定位

> **KTSA 是一个 AI 驱动的企业级商业经营数字孪生平台**，它将公司的组织架构、角色能力、商业模式和外部环境映射到可反复运行的 AI 沙盘中，帮助企业在真实商业代价发生之前，用 20 轮经营模拟预演关键决策、暴露风险盲区、训练团队判断力。

### 4.2 一句话价值主张

**针对 [目标客户] -> 在 [场景] -> 实现 [核心收益]**

- 对 **加速器**：在 **训练营期间** -> 标准化批量评估创业团队经营判断力
- 对 **VC 机构**：在 **投后管理** -> 提前 3-6 个月发现被投企业的风险信号
- 对 **企业培训**：在 **高管战略会** -> 用沉浸式沙盘形成管理层战略共识
- 对 **商学院**：在 **MBA 课程中** -> 用动态案例替代静态案例分析

### 7.2 数据隔离模型

企业数据按租户完全隔离。核心 API 通过 tenantId 作用域进行访问控制。
A 企业无法以任何方式看到 B 企业的工作区、角色、会议、报告和分享链接。

### 7.3 SSO 安全规则

| 规则 | 说明 |
|---|---|
| State 绑定 | httpOnly cookie 保存，回调时校验 |
| 配置绑定 | state 绑定到具体 SSO 配置 |
| 注册控制 | SSO 不开放任意邮箱自动注册 |
| 邀请机制 | 仅已存在用户或已邀请成员可登录 |
| 审计 | SSO 登录写入审计日志 |

### 7.4 LLM 安全治理

| 措施 | 说明 |
|---|---|
| 不存完整提示词 | 日志存储请求哈希而非原文 |
| 成本可见性 | 每次调用记录 Token 消耗和预估成本 |
| 超时和重试控制 | 可配置超时（60-120s）和重试（默认 2 次） |
| 网络代理支持 | 支持 LLM_PROXY_URL 适应企业网络 |
| DNS 强制解析 | 支持 LLM_RESOLVE_IP |

## 11. ROI 分析与价值度量

### 11.1 客户价值指标体系

| 指标 | 定义 | 度量方式 |
|---|---|---|
| 决策质量评分 | 每轮决策综合评分 | 系统计算 (0-100) |
| 风险识别数量 | 模拟中暴露的风险点 | 系统统计 |
| 复盘效率 | 模拟结束到出报告时间 | 即时 vs 传统 2-3 天 |
| 决策可追溯性 | 决策过程完整记录 | 100% 可追溯 |

### 11.2 典型 ROI：VC 投后管理

传统模式：4 小时/次 x 50 家 x 4 季 = 800 小时/年, 成本 $64K + 风险损失 $400K
KTSA 模式：1.5 小时 x 50 家 x 4 季 = 300 小时, 订阅 $60K
年节省：$464K - $84K = $380K, ROI = 6.3x

### 11.3 客户成功案例框架

```
客户: [企业名称]
行业: [行业]
使用场景: [加速器 / VC / 企业内训 / 商学院]
关键成果:
- 风险识别: 提前识别 X 个关键风险
- 效率提升: 复盘准备时间减少 X%
- 成本节省: 替代传统方式节省 $X/年
```
